# IndexPilot Product Roadmap

## Phase 1 — Production foundation

Status: complete

- Next.js + TypeScript foundation.
- Responsive dashboard.
- Phantom wallet integration.
- Risk Engine and unit tests.
- Jupiter API scaffold.
- LIVE/DEMO mode.
- GitHub Actions.
- Vercel production deployment.
- Professional repository baseline.

## Phase 2 — Identity + Solana data

Target: next development cycle

- Reconcile and implement Google OAuth in main.
- Secure sessions and user profiles.
- Wallet-to-user association.
- Cluster-aware Solana configuration.
- Devnet read-only portfolio ingestion.
- SOL/SPL normalization.
- Real portfolio metrics.

## Phase 3 — Solana Testnet release candidate

- Testnet network adapter.
- RPC resilience and monitoring.
- Wallet/network mismatch protection.
- Transaction simulation.
- User confirmation UX.
- Testnet transaction history.
- Integration and browser E2E tests.
- Security review.

## Phase 4 — Intelligence platform

- Real volatility and liquidity metrics.
- Portfolio risk attribution.
- Alerting.
- Agent recommendations with evidence.
- Intelligence API.
- Usage analytics.
- Enterprise workspaces.

## Phase 5 — Enterprise

- Multi-user organizations.
- Role-based access control.
- Audit logs.
- API keys.
- Usage limits and billing.
- Dedicated RPC infrastructure.
- SLA and observability.
- Security program and external audit.

## Product principles

1. Read-only intelligence before transaction execution.
2. Simulation before signing.
3. Explicit network/environment separation.
4. Evidence-backed agent recommendations.
5. User-controlled wallet signing.
6. No production claim without a reproducible test.
